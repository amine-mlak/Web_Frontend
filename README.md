# BEER Küchenmanufaktur

Next.js frontend for the BEER website. Content comes from Strapi.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). CMS is **https://cms.beer.de**. n8n is **https://n8n.beer.de**. See `docs/hosts-cms-n8n.txt`. Set `STRAPI_URL` / `NEXT_PUBLIC_STRAPI_URL` if you override.
