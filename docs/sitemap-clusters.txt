BEER KUECHENMANUFAKTUR
Modeled site map  ·  clusters, pillars, collections
====================================================
Status: keep everything the current site already names,
        plus the clusters BEER used on beer.de / in the
        manufactory offer (islands, ovens, worktops, …).
Audience: Strapi on Christian's server + Next.js routes.

How to read
-----------
PILLAR     = top nav / SEO hub (few, stable)
CLUSTER    = topic group under a pillar (one collection or a folder of pages)
LEAF       = a page or filter term (one entry, or a tag on a project)

KEEP       = already on the live header/footer — must not disappear
ADD        = collection we still need in Strapi
LATER      = nice to have after the first CMS cut

Current live site only has "/" plus hashes. This file is the
target map so those hashes become real URLs later.

                          entdecken, faq, beratung
