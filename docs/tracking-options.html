Tracking and consent: what to choose

Options for each part of the setup, open source, self-hosted and paid, with three ready packages. Pick one package, or one option per part, and we build it. Prices are approximate from vendor and comparison sites; check the vendor's pricing page before signing up.

Where we are. On 26 Oct we chose package A below (paid consent tool + Google Tag Manager + server tracking on Stape). Nothing is built yet: it waits for Christian's accounts. Today the site has Umami (cookieless), but click IDs are saved before consent and the Umami session recorder runs without consent. Both must be fixed before beer.de goes live, whatever you choose.

Rules that apply to every option

What the law and Google require

  • § 25 TDDDG + DSGVO: no tracking cookies, pixels or click-ID storage before the visitor says yes. "Alle ablehnen" must be on the first layer, as easy as "Alle akzeptieren".
  • Google Consent Mode v2: Google Ads needs it in the EU for conversions, remarketing and audiences. Every banner option below can send it.
  • Proof of consent: we must be able to show what a visitor agreed to (consent log). Paid tools do this for us; with open source we keep the log ourselves.
  • Datenschutzerklärung: every tool goes in with purpose, legal basis, storage time, and the US transfer basis (EU-US Data Privacy Framework). This needs a legal check in every package.

What we build on the site

  • One track() function that sends each event to Umami and to the dataLayer (with event_id).
  • Consent defaults "all denied", the banner, and the GTM snippet in the root layout.
  • Click IDs (gclid, fbclid, …) and UTMs saved only after marketing consent; lead records keep them for the CRM.
  • Umami recorder only with statistics consent, or switched off.
  • Footer link "Cookie-Einstellungen" opens the banner again.
  • Events: lead (planner sent), phone/e-mail click, route, appointment booked; later the signed order from n8n as an offline conversion, so the platforms learn from real buyers.
  • GTM containers prepared as importable files, so the agency can take over.
